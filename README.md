**ExpenseEye** is a premium, high-performance financial management application designed for the modern user. Built with Flutter and Material 3, it transforms mundane expense tracking into a visually stunning and insightful journey. Keep a "watchful eye" on your spending with beautiful analytics, intelligent filtering, and a buttery-smooth user experience.

---

## ✨ Key Features

### 📊 Insightful Analytics
*   **Category breakdown**: High-impact Pie Charts with emoji badges for instant visual recognition.
*   **Time-based patterns**: Interactive Bar Charts tracking daily/weekly spending trends.
*   **Real-time totals**: Instant calculations of your total financial footprint.

### 💖 Personalized Management
*   **Favorite Expenses**: Mark frequent transactions (like coffee or commute) for lightning-fast reference.
*   **Smart Filtering**: Drill down by category or specific dates to find exactly what you're looking for.
*   **Detailed Records**: Capture titles, amounts, payment methods, dates, and custom notes.

### 🛠️ Advanced Utilities
*   **Seamless Export**: Share your expense data for external accounting or personal archives.
*   **Expense Splitting**: Built-in logic to handle shared costs with friends or family.
*   **Selection Mode**: Bulk delete or manage multiple expenses with ease.
*   **Local-First Privacy**: Your data stays on your device using encrypted-ready SQLite storage.

---

## 🎨 Premium UI/UX

*   **Glassmorphism & Shadows**: Subtle depth effects that make cards feel tactile and real.
*   **Curated Palettes**: Harmonious HSL-tailored colors for categories like Food 🍽️, Transport 🚗, and Shopping 🛍️.
*   **Fluid Animations**: Powered by Flutter's animation engine for smooth transitions between dashboard and analytics.
*   **Responsive Layouts**: Optimized for mobile devices with `SafeArea` support for gesture navigation.

## 🚀 Getting Started

### Quick Install (Android)
1. Download the latest **APK** from our [Release Page](https://github.com/MohammedSafwan10/expense_eye/releases).
2. Open the file on your smartphone and tap **Install**.
3. Start tracking in seconds!

### Developer Setup
If you want to customize or build from source:

1.  **Clone & Navigate**
    ```bash
    git clone https://github.com/MohammedSafwan10/expense_eye.git
    cd expense_eye
    ```

2.  **Sync Dependencies**
    ```bash
    flutter pub get
    ```

3.  **Launch!**
    ```bash
    flutter run
    ```
